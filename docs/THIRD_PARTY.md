# Third-party scope

Keepweft's project-owned code, tests and documentation are licensed under
[MIT](../LICENSE), copyright 2026 Andrew Yuan. This does not relicense external
components. Checked against upstream license texts on 2026-10-24:

| Component | Terms / source | Relationship |
| --- | --- | --- |
| Python and standard library | [PSF license and included notices](https://docs.python.org/3/license.html) | External runtime; no interpreter or stdlib source bundled |
| SQLite | [Public domain](https://sqlite.org/copyright.html) | External linked library; no SQLite source or binary bundled |
| setuptools | [MIT](https://github.com/pypa/setuptools/blob/main/LICENSE) | External build tool; its vendored dependencies retain their notices |
| wheel | [MIT](https://github.com/pypa/wheel/blob/main/LICENSE.txt) | External build tool |
| Colima | [MIT](https://github.com/abiosoft/colima/blob/main/LICENSE) | Optional external Linux-validation infrastructure |
| Lima | [Apache-2.0](https://github.com/lima-vm/lima/blob/master/LICENSE) | External VM infrastructure used by Colima |
| Ubuntu packages and compiler toolchain | Respective package copyright/license notices | Installed inside the temporary VM; not redistributed by this project |

`pyproject.toml` declares no additional runtime Python packages. Imports use the
project's own modules and Python standard library, including `sqlite3`. Test data
is generated by the project's ledger code; no external model or dataset is used.
No upstream runtime source, compiler output, VM image, package wheel or third-party
binary is committed. The runtime wheel contains project modules, distribution
metadata and the project MIT license, not these external components.

No conflicting redistribution obligation was found for this distribution scope.
If interpreters, libraries, VM images or toolchain components are later bundled,
their own license and notice obligations must be checked for that distribution;
the project MIT grant does not replace them.

The isolated Linux validation builds SQLite 3.54.1 from the official HTTPS
amalgamation archive and verifies the sqlite3.c SHA3-256 published in release
history: https://sqlite.org/changes.html. The receipt records archive hash,
compiler flags, actual library hash, loaded-library mapping and runtime source ID.
The native SQLite version is reported separately. Passing experiments does not
certify arbitrary distro backports or SQLite builds.
